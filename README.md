## Documentation

The documentation is available on [docs.kioku.chat](https://docs.kioku.chat).

Repository note: `services/vexa` is a Git submodule from
`https://github.com/kioku-org/vexa`. Clone with `--recurse-submodules`, or run
`git submodule update --init --recursive` after cloning.
